# Build a Complete Local Mart Marketplace App

Build a modern, production-ready **multi-vendor grocery/mart marketplace application** where local marts can register their businesses, add and manage products, and customers can discover nearby marts within a **5 km radius**, browse products, add items to cart, and place orders.

The application should have **three main roles**:

1. Customer/User
2. Mart/Store Owner
3. Super Admin

---

## 1. Customer App

### Location Detection

When the user opens the application:

* Request permission to access the user's location.
* Automatically detect latitude and longitude.
* Determine the user's current area.
* Find registered marts within a **5 km radius**.
* Sort nearby marts by distance.
* Show the distance from the user to each mart.
* Allow the user to manually change their delivery location.
* If location permission is denied, allow the user to enter their location manually.

Use Google Maps/Mapbox or another reliable maps and geolocation service.

# 13. Nearby Mart Algorithm

Implement location-based mart discovery.

For every registered mart, store:

* Latitude
* Longitude

When a user opens the application:

1. Get user's latitude and longitude.
2. Calculate distance between user and all active marts.
3. Only return marts within **5 km**.
4. Sort by nearest distance.
5. Display distance on each mart card.

Use the **Haversine formula** or geospatial database queries.

Example:

User location:
`12.9352, 77.6245`

Mart A:
`1.2 km away`

Mart B:
`2.8 km away`

Mart C:
`4.7 km away`

Mart D:
`7.2 km away → Do not show`

If there are no marts within 5 km:

> "No marts found within 5 km."

Then provide:

**Expand search radius**

Allow users to search up to 10 km if desired.

# 18. Important Business Rules

Implement these rules carefully:

1. Only approved marts appear in customer search.
2. Only active marts can receive orders.
3. Marts outside the selected radius should not appear.
4. Products marked out-of-stock cannot be ordered.
5. Customers cannot combine products from multiple marts in a single order.
6. Mart owners can only manage their own mart and products.
7. Admin has complete system access.
8. Order prices must be stored at the time of purchase so historical orders don't change if product prices change later.
9. If a mart is closed, users can browse it but cannot place an order.
10. If a product becomes unavailable after being added to cart, validate stock again during checkout.
11. Prevent duplicate orders caused by repeated payment requests.
12. Validate payment status through the payment gateway before marking an online order as paid.
